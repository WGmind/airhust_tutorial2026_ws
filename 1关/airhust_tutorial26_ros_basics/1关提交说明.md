## 2.遇到的问题

### (1)从windows拷贝项目导致无法运行
win的git在克隆时和linux表现不一样（符号链接等）还出现一堆奇怪字符比如`command not found: ^M`（貌似是系统换行区别）
解决：在ubuntu里进行git clone

### (2)install和devel的环境互相覆盖（环境变量）
执行roslaunch后报错RLException: [mission.launch] is neither a launch file in package [drone_bringup]
source install/setup.zsh 后找不到drone_bringup
source devel/setup.zsh 后找不到drone_backend
不知道是不是我搞错什么了 用下面方法解决了
解决：
```bash
source /opt/ros/noetic/setup.zsh
source install/setup.zsh
source devel/setup.zsh
export ROS_PACKAGE_PATH="$ROS_PACKAGE_PATH:$PWD/install/share"
export CMAKE_PREFIX_PATH="$CMAKE_PREFIX_PATH:$PWD/install"
```
